TextLift VERSION 1.0.1
This page does not allow the text picker.

Try an ordinary website. Chrome blocks extensions on its settings pages, the Chrome Web Store, and some built-in viewers. For a local HTML file, enable “Allow access to file URLs” in TextLift’s extension details. If you have just reloaded the extension, refresh the website too.

THE WORDS YOU NEED. ONE CLICK AWAY.

Point. Pick.
Copy.

Buttons, tabs, menus, and labels.
Take their text with you.

  1. 01

    Start the picker

    Click the TextLift icon in Chrome, or press Alt + Shift + L. Pin the extension for easy access.

  2. 02

    Point at your text

    A green outline shows what you will capture. Click once to bring the words into the preview. Page clicks are paused while picking.

  3. 03

    Make it yours, then copy

    Edit the preview or select a few words, then choose Copy text or Copy selection. Press Esc to close, or choose Pick again.

Your text stays with you.

TextLift runs when you invoke it. It sends no text to a server, keeps no copy history, and never reads your clipboard. Password fields are excluded.

Version 1 reads webpage text and available labels. Text inside images, canvas drawings, embedded pages, and closed web components may need a different method. A label from an icon is marked “Accessible label.”

If the shortcut is already in use, assign a different one in Chrome’s extension shortcut settings. Chrome 116 or newer is required.
