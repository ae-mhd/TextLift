# TextLift store listing

## Name

TextLift

## Short description

Pick and copy text from buttons, tabs, links, and labels on demand.

## Detailed description

Copy the words you need from buttons, website tabs, menus, and labels that are difficult to select.

Click the TextLift toolbar icon or press Alt+Shift+L to start the picker. Hover over an element to see its text and a green outline. Click to capture it without activating the underlying button or link. Edit the preview, select just a few words, and copy the result.

Features:
- Live preview and an outline around the element you are pointing at.
- Page clicks paused during picking, then restored after capture.
- Editable text and copying of selected words.
- Pick again for another element; Escape to close.
- Basic line breaks, Unicode text, and open web components.
- Available labels for controls without visible text.
- Clipboard copying on HTTP and HTTPS pages.

TextLift processes webpage text locally. It does not transmit captured text to a server, keep a saved copy history, show ads, or run analytics. Password fields are excluded. It never reads your clipboard.

Version 1 reads webpage text and available labels. It does not recognize text inside images or canvas drawings, and embedded frames and closed web components are not supported. Chrome restricts extension access to internal pages, the Web Store, and some built-in viewers. Local HTML files need Chrome's separate file-access toggle. Shortcut conflicts can be resolved in chrome://extensions/shortcuts.

Requires Chrome 116 or newer. No account or subscription is needed.
